# BI Team Website

A modern, responsive static website for the Business Intelligence Team.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Navigation**: Sticky navbar with smooth scrolling
- **Team Overview**: Showcase your BI team members and roles
- **Dashboard Links**: Quick access to interactive dashboards
- **Reports Section**: Display regular and ad-hoc reports
- **Resources Hub**: Central location for documentation and tools
- **Contact Information**: Easy ways to reach the BI team

## Structure

```
website/
├── index.html          # Main HTML file
├── assets/
│   ├── css/
│   │   └── styles.css  # All styling
│   ├── js/
│   │   └── main.js     # Interactive features
│   └── images/         # Place images here
└── README.md           # This file
```

## Getting Started

1. Open `index.html` in your web browser to view the site
2. Customize the content in `index.html` to match your team details
3. Add your team's logo and images to `assets/images/`
4. Update contact information and links to your actual dashboards

## Customization

### Colors
The color scheme can be modified in `assets/css/styles.css` by changing the CSS variables:
- `--primary-color`: Main brand color
- `--secondary-color`: Secondary brand color
- `--text-dark`: Dark text color
- And more...

### Content
Update these sections in `index.html`:
- Team member cards
- Dashboard links
- Report schedules
- Contact information
- Company/team name

## Deployment

This is a static website that can be hosted on:
- Azure Static Web Apps
- GitHub Pages
- Netlify
- Vercel
- Any web server

Simply upload all files maintaining the folder structure.
